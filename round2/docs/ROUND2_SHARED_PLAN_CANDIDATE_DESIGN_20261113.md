# S3/P6候选设计：同初始计划，观察后是否允许改计划

2026-11-13。设计先于实现；后续S2及S3已按范围验收，见[成品报告](../reports/ROUND2_SHARED_PLAN_CANDIDATE_ACCEPTANCE_20261113.md)。正式LLM临床批次尚未启动。以下保留设计依据，执行参数以冻结P7协议为准。

## 原始依据和作者实现核查

- [ReAct论文](https://arxiv.org/abs/2210.03629)：观察与行动交替，后续计划可依环境返回改变。核对作者[HotpotQA notebook](https://github.com/ysymyth/ReAct/blob/master/hotpotqa.ipynb)的逐步action→environment.step→observation循环和终止／步数限制；借鉴观察后的控制接口，不复制问答few-shot、任务样本或其成绩。
- [ReWOO论文§2.1](https://arxiv.org/html/2305.18323v1#S2.SS1)：规划→工具执行→求解解耦。核对作者[Planner.py](https://github.com/billxbf/ReWOO/blob/main/nodes/Planner.py)的完整规划生成，以及[Worker.py](https://github.com/billxbf/ReWOO/blob/main/nodes/Worker.py)工具组织。固定组借鉴预规划执行；本项目无需其跨工具变量替换，不声称完整复现ReWOO，也不沿用它的训练或benchmark提升。
- S2继续使用[共同权限／成本契约](ROUND2_TOOL_ACCESS_COST_CONTRACT_20261113.md)；MCP接口与真实患者信息获取费用不是同一概念。

## 候选接口和唯一主差异

新增显式候选入口，不替换生产`planned_react`。两组共同生成且复用一份初始规划JSON，规划只可看到本例已给出的prompt、同一工具schema和预算，不能读取质量台账、病例索引、隐藏病历或GT。初始计划以输入／源码／模型／资源指纹绑定并落盘，不允许第二组再生成。

初始计划包含至多6个有序动作：临床工具`tool`、指南工具的`query`、简短`purpose`。病例ID由执行器注入；不能由模型切换病例。空计划合法，不强行添加工具。非空计划的第一个动作两组共同执行；只有观察返回以后才开放自主组的修订权限。

- **固定组**：继续执行已冻结的剩余动作，不因观察内容新增、换序或提前临床停止；到计划结束／共同动作上限停止。
- **可修订组**：观察后输出下一合法动作及更新后的剩余计划，或明确stop。允许替换工具、改变指南查询、重排和提前停止。相同工具集合、信息预算、获准尝试额度与最多6次取证请求；最多5次观察后策略轮次，执行最后获准请求后统一收口。

工具拒绝和无资料均是真实观察，但不变成成功揭示；后端异常、非法动作或无法解析的控制输出明确失败。并发预算在MCP层原子预留；同一输出目录只允许一个写入者。没有模型可调用的提额、换病例或原始文件读取工具。

## 共同诊断与记录

两组取证结束后进入相同诊断生成、结构化填表与核验；共同诊断只接收初始信息、实际合法观察、预算和初始计划，不把策略中间评论当新临床证据。默认生产后处理不接入本候选；LLM解析判断、核验判断和禁用后处理状态分列，结论范围是该共同输出模块下的取证策略。

predictor、影像衍生预测与病例few-shot在两组共同明确排除，且配置启用时直接拒绝；这只证明排除范围的安全边界，不证明这些组件合法运行路径已适配。指南检索必须实际合法接通，不能一直拒绝后宣称成品。

每次模型调用记录阶段、请求消息、返回、usage／耗时；每次工具请求记录目的、授权／返回、资源和预算变化；策略轨迹与LLM判断分开。共享规划计算成本单独报告，配对总体只计一次，共同分摊时说明口径。原始消息与输入hash可重放；重放不算新增模型生成。

## 先验收，再冻结对照

脚本模型通过真实MCP验证：同一计划复用、共同第一观察、固定组不改计划、自主组确实依据不同观察改变动作／停止、指南合法返回、预算／跨病例拒绝、缓存／失败／恢复，以及末端无旁读。脚本回答不具有医学意义，不作准确率证据。

接口验收通过后形成P7协议与清单，登记样本来源和接触史、分组、模型／源码／资源指纹、主要与次要指标、任务量、失败分母及停止条件。先给用户审查；不因为Goal开启自动启动正式临床生成，不扩到节点策略或RAG算法比较。
