# 执行会话 Goal 与审查条件

2026-11-13。用户明确分工：`主会话`执行并持有 Goal；`详解`建立条件、解释与审查，不承担执行目标，不同时修改生产代码。详解误建的 Goal 已暂停。

## 执行目标

接续当前已完成的 S2/P4 和正在实施的 P5，完成共同信息权限／成本边界的全链验收，再交付 S3/P6 固定初始计划与观察后可修订计划的完整候选，最后形成 S4/P7 可审阅、可冻结的对照协议与运行清单。期间按门槛持续推进，不要求用户为每个小步骤重复发送“继续”。实际状态以现场文件与结果为准，不从头重跑已完成步骤。

## 本次允许自主执行

- 必要的原始论文／作者实现核查、代码实现、针对性测试、脚本化模型及真实 MCP 工程验收、资源与数据来源核对。
- 保持默认生产行为与旧实验结果；新增模式显式开启。新路径失败要明确失败，不用无声回退取得表面成功。
- 缺少独立 dev/test 或患者确认时继续可独立完成的工程工作，保守分组并准确限定结论，不伪造独立数据。
- 正式新增 LLM 临床生成／性能批次先交付成品与协议供审查；本次 Goal 不自行启动该批次，不提交平台、不换模型、不开展后置研究。

## 阶段验收与审查证据

| 门槛 | 必须证明 | 不能替代的证据 |
|---|---|---|
| S2/P5 | 逐病例绑定和恢复；执行前原子预算；planner 预执行与 ReAct 共用边界；few-shot 查询无隐藏回填；predictor／影像允许与拒绝条件明确；指南资源版本与实际合法检索可核验；失败、并发、缓存／重试和跨病例负例；填表／后处理无旁读 | 只测 MCP；只在 prompt 写成本；仅停用所有通道而称全部路径已验收 |
| S3/P6 | 两组共用规划能力、工具集合、信息权限、预算与输出；固定组按计划执行，自主组能依据观察修订、取证或停止；有真实执行轨迹及受控脚本测试；错误与预算耗尽可重放 | 删除 planner 即称自主；接口冒烟即称完整候选；用伪造判断声称医学提升 |
| S4/P7 准备 | 唯一主要差异、固定项、患者／版本分组及接触史、源码／模型／检索资源指纹、主要与次要指标、任务量、种子、失败处理、晋级／停止规则 | 先跑分再选指标或预算；重复轨迹算新增患者；末端成绩覆盖 LLM 阶段改善 |

对尚未授权的 predictor／影像显式拒绝可作为安全边界验收，但不代表其合法运行路径已经接通。若成品对照不使用它们，须在两组范围中共同明确排除，保留单独待办；指南检索等候选所需能力不能一直拒绝后仍宣称完整交付。

离线冲突台账的隐藏原文及派生质量标签不得免费进入任何判断组件。LLM 判断、审核、后处理分列；信息代理成本、官方工具分、计算成本分列。

## 持续运行与结束规则

必要测试通过后直接推进下一门槛，少做重复盘点与状态文案。出现失败先定位具体机制再修复，不搜索诊断标签或无限调 prompt。形成决定性结果先分析，不为占满时间追加实验。

执行会话仅在上述完整目标逐项有证据时标完成，提交文件位置、运行命令／结果、证据局限与剩余事项。审查会话独立读取证据判断通过／待补／不通过，不能把“文件存在”当通过。缺口不得通过缩小原目标悄悄消除。

本审查文档不承诺自动定时唤醒或跨会话回报。用户已授权把本条件发送到执行会话；未授权自动回传消息时，以共享文件和只读检查审查。
