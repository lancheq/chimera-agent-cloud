# 受控试跑的运行与回执合同

## 输入权限

按[官方输入定义](https://chimera-agent.grand-challenge.org/data-sources-and-imaging/)区分初始可见字段和经 MCP 取得的资料。试跑许可绑定任务、最小只读视图、配置、工具白名单和资源上限。正式入口与 MCP 子进程核验相同的权限范围。隔离检查覆盖意外可读的数据根、参考文件、缺失挂载、任务错配和视图改写。先通过零生成验收，再开放模型请求。

## 回执与恢复

工具名来自先前的已授权请求。返回回执通过请求编号、摘要、事件顺序与出账记录关联到请求。缺失、重复、错绑、越权或账本未结算均触发停止。对误报先保全原记录并离线核对，从冻结清单中只继续未执行项。补做服务身份核验时，非生成开销和正式推理预算分账。合成回归覆盖绑定、拒绝和账本一致性。

## 审计与晋级

请求、实际工具返回、诊断、填表和平台输出分别记录。对时间结局任务，观察随访、预测时域和首次出现环节分别核对。历史资料可得性仍需独立的来源和时间证明。正式 validation 由 B 线准入和同一镜像、模型、配置的离线证据共同决定。训练集结果和个案证据在禁发期保留于本地。[赛事规则](https://chimera-agent.grand-challenge.org/rules/)
