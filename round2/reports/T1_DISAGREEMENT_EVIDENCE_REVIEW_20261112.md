## 问题与固定对照

上一轮两特征概率融合未提出任何可靠改判。这次不是降低其门槛，而是一个不同的干预：**预测器与原判断分歧仅触发复核，不赋予预测器直接覆盖权。**

采用最早完整 Phase 2 无预测器提示队列的原始核验判断，以及上轮已冻结的逐折预测器概率，不重新训练。按二者二分类标签不一致选出 **30/91 例**，包括 26 例 LLM=yes/预测器=no、4 例反向；没有按参考标签筛选。

| 策略 | 信息与行为 | 新模型调用 |
|---|---|---|
| 保留原判断 | 全部 91 例原判断 | 无 |
| 原固定 v2 | 相同冻结概率上的历史覆盖规则，描述性对照 | 无 |
| 上下文复核 | 原核验判断、预测器意见、最初可见记录 | 分歧病例真实复核与独立审核 |
| 原始证据复核 | 同样输入，额外提供此前实际成功返回的临床工具原文 | 相同流程的真实复核与独立审核 |

两个真实组采用相同的中性指令、解码配置与接纳规则，病例内匹配请求种子和本地服务，分支顺序按固定哈希交替。此处“独立审核”指分离上下文和调用，不代表采用独立模型家族或外部临床专家。

## 证据和改判的约束

- 原始意见取自 **verified_judgment、后处理之前**，不把历史全局权重/置信度表重写的结果作为 LLM 原意见。
- 原文只能来自成功、病例 ID 匹配的既有临床 ToolMessage；重复返回去重，保留实际工具调用 ID 和来源字段。
- 结构化记录以字段路径和原始叶值显示；没有导入隐藏独立 `cspca`，没有新检索或额外指南请求。已生成解释不能作为一级证据。
- 新判断必须完整包含决策、置信度、所有可用变量权重、解释和后续计划，并引用提供记录中的连续原文。
- 单独审核只看提议结果与一级证据，不看原判断或量化模型意见；检查事实支持、决定与理由一致、计划一致。必须回传正确病例、确切结果哈希和已审字段。
- 全部通过才接纳完整结果；否则保留完整原记录并记录拒绝原因。接纳后不再运行 v2 或其他改变文字/诊断的校准，避免再次拼出矛盾结果。
- 程序证明的是引用/接口完整性，自动语义审核也可能出错。临床正确数由独立于模型输入的参考标签计算，不能用审核通过率代替正确率。
