## 冻结执行范围

计划继承 A-F06 的 Adaptive 单例、受信工具白名单和原预算停止合同。D01 为逐任务 Adaptive，D02 排除 Reflection/atomic，D03 排除 predictor、few-shot 和影像取材，D04 只允许已批准的冻结 RAG、排除 B/C02，D05 沿正式表单与双 Socket 且无诊断覆写，D06 保留 G1T 最终 SDK JSON、后端原生计数和硬预算，D07 使用私有审计。T1 排除当前活检病理及家族史，T3 排除通用 `months`、复发/末次随访和跨任务工具，真实链路尚未验收。未登记人工例外。

保留单 slot、一次空闲 GPU 恢复、单并发和八 CPU 线程上限。每例 12 次真实发送、3 信息单位、6 次工具申请或受理、5 策略轮，总预留 195,072 token。三例预留合计 585,216 token。隐式 SDK 重试为 0。所有实际病例计数均为 0。

## 零生成验收与交接

私有 intake 的四项回归覆盖稳定排序和跨任务风险去重、输入改写及软链接及重复键拒绝、T3 禁用字段识别、隔离外参考文件对进程及子进程不可见。使用无患者合成数据，挂载仅验证了最小文件系统边界。根入口 Adaptive、预算停止和 G1T 请求边界另有 81 项通过，覆盖合成双 Socket、T3 字段隔离、预算封存和拒绝路径，耗时 483.1 秒。两组测试均用单 worker，正式入口测试的 SDK 用 MockTransport，原生计数未运行。证据及指纹见私有交接。 [私有交接](../output/g2_case_pilot_20261119/handoff.json)
