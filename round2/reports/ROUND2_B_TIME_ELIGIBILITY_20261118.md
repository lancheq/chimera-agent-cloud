## 原始内容的最小隔离接点

**在已授权原件核验完成后、写入决策状态前，生成同一安全视图。** 目前 B 的日期门槛只处理注记，合成 SDK 兼容把有凭证的 MCP 工具文本按原字节送到请求。初始 socket 也会通过渲染文本和完整 JSON 两条路径进入首轮。只关闭 B 注记会留下两条原文路径。

保全原 socket、MCP 原件和权限账本，初始输入投影后再渲染，工具结果在原生形状、结算凭证及 `tool_call_id` 核验后再进入 graph。结构字段或完整行按截止证明选取，不能可靠拆分的整段内容改为固定缺失占位。保持工具调用 ID、既有出账与原件可核。直接 ReAct、预算停止后的消费者和终审读同一视图，旧历史按相同策略重新证明。G1T 在投影后计量最终 JSON 并核对 HTTP 序列化字节。坏绑定、未证实 cutoff 或审计失败不得形成候选成功结果。 隔离接线与审计 · [B 工程验收](ROUND2_B_MCP_SDK_PLANNING_REVIEW_20261118.md) · [G1T SDK 边界](ROUND2_P01_G1T_SDK_REQUEST_BOUNDARY_20261118.md)

## 规划决定与本轮边界

后续可用 Phase2 每任务最多 6 个保守风险组、总计最多 18 条固定槽做只读侦察。先核官方截止和授权，再核初始可见证据与既有成功返回；同组不跨任务或集合，跳过与 UNKNOWN 不补样。接线验收只复用既有合成资料。任一未来原文泄漏、错绑、重复结算或不可核验模型视图即停止。真实 G1T 模板计数仍单列待验。 最小验收与抽样
