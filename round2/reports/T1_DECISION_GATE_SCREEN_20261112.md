# T1 决策层下一步：嵌套交叉拟合的条件干预筛查

日期：2026-11-12。当前只验证“预测器是否有足够证据覆盖原始判断”，未启动新的 RAG、RL、取证策略或生成提示实验。

**结果：本候选未通过提分筛查。它在主队列和四组补充上下文上都保留了全部原始判断，因此不是一个提分方案。按事先冻结的条件，本轮不启动真实 LLM 复核，不调整置信门槛寻找更好分数，生产配置不变。**

## 运行准备：实现与隔离已通过

新增实验模块 `agent/decision_gate.py`：

- 允许两个方向提出改判：yes→no 或 no→yes，不再内置单向否决偏好。
- 只有训练折 bootstrap 估计区间完全支持相反标签时，才产生 `review_required` 提议；否则保留原判断。
- 提议不能直接改写诊断。`stage_t1_proposal()` 保留完整的旧判断、解释和计划，另存待复核提议，避免“新诊断搭配旧理由”。实际证据复核与应用接口在筛查通过前不接入。
- 没有接入默认执行图，没有修改诊断 prompt、临床阈值、检索规则、已发布模型或 v2 系数。

自动化测试 **61 passed**（新增 7 项）；两项警告来自既有合成 fixture 的 enum 序列化。新增测试覆盖对称提议、边界和异常值、未复核不覆盖、所有内层训练排除外层患者、训练查询自排除，以及序列化后的模型预测一致。

## 冻结的实验设计

配置在计算新候选结果前写入 `output/t1_decision_gate_20261112/protocol.json` 并保存哈希。此前已接触这 91 例，因此这叫本轮设计冻结，不能称为未接触数据的预注册验证。

- **主队列**固定为最早完成的无预测器提示 Phase 2 真实取证队列 `actual_collection03`，依据时间顺序选择，不选择分数最好的夜间队列。
- 按患者进行外层 5 折（seed=42），内层 3 折（seed=1729）。内层重新产生训练用 OOF 概率，禁止直接使用已有的全局 OOF 概率训练融合层。
- 每个外层折只用该折训练患者拟合预处理、kNN 和基础分类器。门控用“概率差、LLM yes/no”两个特征，固定 LR 配方，不搜索特征和参数。
- 每折用 200 个训练患者 bootstrap 样本估计融合模型的条件不确定性；固定 2.5%–97.5% 区间。它只表示该元模型拟合的不确定性，不包括基础模型和提取器的全部不确定性，更不是临床可靠性保证。
- 每个外层基础模型及门控序列化一次，之后用同一模型评估四组既有取证上下文。补充上下文不再重训预测器，从而去掉上轮跨组混入的重训差异。
- 所有外层验证患者都被排除在基础模型、内层索引、融合拟合和 bootstrap 中；保留逐折训练 ID 清单。

对照包含：保留原始判断、历史固定 v2、嵌套重训融合点估计、条件干预候选。点估计是用于诊断“是否仅因区间太保守”的消融，不作为备选策略择优部署。

## 如何解释这个阴性结果

1. **不是接口没有执行。** 单元测试证明提议器能够在两方向触发；真实数据的点估计融合本身就没有改变原始标签，所以不能仅归咎于 bootstrap 区间太保守。
2. 五个外层折中，概率差的系数分别约 **+0.498、+0.128、−0.051、−0.207、+0.461**；每折的 bootstrap 区间都跨 0。LLM 判断项的系数则均为正。当前数据不支持一个稳定的“依据这个预测概率覆盖 LLM”的关系。
3. 主队列中历史 v2 修改 24 例，12 例由错变对、12 例由对变错，总分持平。新候选保留原判断虽然避开这些错误覆盖，也同时放弃那些正确修正，不能称为提分。
4. 结果只否定这套固定的两特征融合/条件干预候选，不能证明预测器绝无信息。内层基础模型的训练样本比外层模型更少，区间也没有覆盖所有不确定性，这些限制都不能省略。
5. 现有 91 位患者已经参与历史模型、索引或 v2 选择。嵌套交叉拟合改善本轮泄漏控制，不会消除历史选择偏差；五种上下文也不是五批独立患者。

## 当前决定

- **这一候选的筛查结束，不进入真实 LLM 复核或生产启用。** 没有待复核提议，继续为它安排 LLM 调用没有意义。
- 可靠的改进方向仍应针对已有事实：冲突病例需要引用可追溯的实际证据，改判后的理由与计划需要重新核验。这个方向与“再加一个概率阈值”不同，不能通过降低本轮门槛来伪装通过。
- 下一项应作为单独、固定规则的“模型分歧触发证据复核”候选，保留无覆盖与原 v2 作对照，按患者隔离评估。在这项设计明确前，本批不追加运行。
