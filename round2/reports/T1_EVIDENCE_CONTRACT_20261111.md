## 实现边界

新模块 `src/chimera_agent_baseline/agent/evidence_features.py` 只消费成功的、病例 ID 匹配的 `get_mri_report`、`get_psa_trend`、`get_lab_results` 返回。支持 MCP 文本块、JSON 和已有轨迹中的 Python 文本块表示。AI 自述、失败返回、其他病例、隐藏临床字段均不用于补值。

- 仅补 T1 缺失的 `psa / psad / vol / pirads_int`；保留 prompt 原有有效值，包括零。
- PSA 使用可确认的最新日期；月份按整月区间处理。日期重叠、未知日期和互相冲突的值不擅自排序。Free PSA、范围和不支持的单位不作为精确总 PSA。
- PI-RADS 优先使用明确的报告结论段，去除版本号干扰；不同评分冲突时保留缺失，不取最大值。区间评分不转成单值。
- 体积和 PSAD 只接受明确报告值；不按 PSA/体积反算。保留证据片段、工具调用 ID、字段、日期、候选值和冲突状态。
- 现有 MCP 没有返回独立 `cspca` 字段，继续缺失，不从临床文件暗补。
- `predict()` 与 `explain()` 接收同一份字段；原始 prompt 不改写。开关开启时，只把成功且确实返回相应段落的病例匹配工具计入 reveal mask。
- 源码身份记录新增特征装配、预测器节点及预测器文件哈希。研究采集支持完整 trace，默认仍保持 8000 字符上限；该诊断选项不改变模型输入。

## 91 例内部 OOF 筛查

先发现并记录数据重叠：Phase 2 有标签的 91 例 T1，**全部属于当前模型的 91 例 kNN 索引**。因此没有用现成模型的同批预测作为泛化证据。

本次使用固定五折、seed=42、原有 LR 配方（C=0.5，balanced）；不选模型、不搜参数、不添加伪标签。原版发布中的训练特征用于训练各折，Phase 2 输入用于评估。每折单独拟合 imputer、scaler、encoder、reducer（如启用）、kNN 和分类器；评估病例与该折索引的交集均为空。三组共享同一折模型。跨发布核对了共有结构化字段、PSA 历史、实验室、家族史及标签一致性；MRI 文本有改写，未按同名文件假定文本相同。

这次仍是假设三个来源工具全部打开的预测器上限筛查，不是真实 agent 或最终决策准确率。

| 同一折模型上的输入 | 正确数 | 准确率 | Brier | 相对缺失基线修正/损坏 |
|---|---:|---:|---:|---:|
| 原始缺失输入 | 52/91 | 57.14% | 0.3091 | — |
| 恢复标量，冻结基线 kNN 查询 | 46/91 | 50.55% | 0.3130 | 2 / 8 |
| 恢复标量，并同步 kNN 查询 | 58/91 | 63.74% | 0.2461 | 13 / 7 |

完整装配的准确率差 +6.59 个百分点，配对 SE=4.89 个百分点，证据不足以认定稳定提升。仅恢复标量反而损伤准确率；不能把完整路径中的变化都归因于标量值本身。当前只证明需要一致处理分类器输入和相似病例查询。

同一配方重跑得到相同结果，属于可复现检查，不增加独立样本数。机器报告：`output/t1_evidence_contract_20261111/oof_screen02/report.json`，病例与折分在同目录。历史上模型族、超参数与 v2 层曾接触这些患者，内部 OOF 不能消除这段选择历史。
