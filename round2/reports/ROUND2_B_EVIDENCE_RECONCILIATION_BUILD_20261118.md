## 入口、来源与输出

`inference.run(..., _evidence_test=...)` 只接受代码注入、已验证的合成 profile，并要求现有信息守卫与 guarded ReAct 路径、任务和病例匹配。默认入口及配置保持原样。入口继续使用 `run_agent → prepare_case → Graph agent/ToolNode → form_fill → prediction.json → 两个 Socket`。B 只在原有 agent 请求附加状态与证据引用，不复制原值、报告全文或工具原文。合成测试将其从请求中移除后，剩余载荷与对照相同。

初始来源绑定到入口已交付文件及其摘要。工具来源要求当前 ToolNode 的调用 ID、工具、参数、已核原始结果和同一绑定下唯一新结算成功事件相符。SQLite 账本提供请求 ID、内容摘要和实际取得时间。缓存、跨病例或运行、同批同工具归属不清、未授权返回、文本自报授权及伪造回执均不创建新 B 来源。KB、模型输出、病理及 MRI 自由文本未进入 B。

## 时间、冲突与回退

复用 B02 已审查的事件和时间关系表示，以及仓库的 `date_interval` 月份区间。观察、报告、原来源截止可得性和账本实际取得时间分别登记。研究方案中的全量病历访问、推断日期坐标、多轮生成或模型训练无法保持本项目的可见输入和预算，因此未引入作者实现。B01 的 66 条是恢复映射，认证解消为 0。本轮没有打开其逐例资料。详见 [B01](ROUND2_EVIDENCE_RECOVERY_FEASIBILITY_20261117.md) 和 [B02](ROUND2_B02_LITERATURE_FEASIBILITY_20261117.md)。

只有明确可比的变量、实体、口径、方法和单位才能比较。带相同可信观察标识、相容观察时间及不同原值的记录保留为未裁冲突；确定不同的非重叠时点单列为不同时间。日期重叠、仅有报告日期、实体或方法缺失时保留未知或不可比。缺失、否定、计划和不确定分别标注，未加入增长、单位转换、诊断或治疗规则。

已知越过历史截止的观察、报告、可得性或越过独立运行取得期限的工具结果均从 B 状态排除。无法证明截止可得性的记录也不参与比较。运行时取得时间并非临床时点。此门禁约束 **B 注记**，原有证据通路仍按自身信息合同运行。若生产需要从原始请求隔离已知晚到的合法工具内容，须另定权限和溯源规则。坏日期或冲突元数据触发原路径回退，身份或预算拒绝仍沿用既有失败语义。
