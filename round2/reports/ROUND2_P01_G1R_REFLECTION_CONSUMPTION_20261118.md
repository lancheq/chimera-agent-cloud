## 实际消费链

- 入口沿 `inference.py → run_agent → graph → form_fill` 运行。填表先解析当次动态 schema 的完整 J0，再对唯一合成候选核对 run、task、case、profile、草稿、J0、来源、过程、候选和审核覆盖。合法 null 保留。缺必要决策时致命退出。引用只取自入口实际渲染的预展示记录区，且须能定位到该区。本轮无已获工具结果的授权适配。
- 合成授权来自测试进程注入的 Python 入口及已验证的合成 profile。纯选择器返回完整 J0 或完整候选。真实赋值后的对象、atomic 前的对象和选择回执摘要逐一核对。表单 prompt、默认配置和常规后处理顺序保持原样。
- 复用 G1A 私有账本。组装、图输出、prediction 回读、T1/T2 的 align 和两个最终文件均有阶段关联及逐字段回执。写出成功 `finalized` 与候选保留状态独立记录。历史未审内层分支既有写回在合成入口单独回归，新授权路径不借用该行为。

## 保全与验证范围

G1A 接续时核验 69 项源码身份。保存改前副本和本次变更差异，新旧配置与任务输入的保全明细见本地清单。运行期间观察到任务卡、AGENTS 和 CURRENT 的外部更新，以及项目 Codex 模型配置出现，本任务保持这些变更并重新读取当前规则。另更新了 G1A 回归中已替换的占位状态断言，历史 G1A 产物保留。

合成集成使用进程内 HTTP 假响应、空临床资料和现有本地 stdio 工具发现。G1R 入口共记录 40 次模拟 SDK 请求，真实模型端点、患者取证、GPU、训练、构建、部署、上传与平台操作均为 0。开发探测的线程峰值曾达到 6 和 5，保留原采样。最终限额复跑耗时 54.36 秒，采样峰值为 2 进程、4 线程、约 708 MiB。

后续规划要决定外层结构提议的生产来源、审核覆盖及后处理权威。当前适配成本为零新增模型请求。若沿用既有调用无法产出可绑定的结构提议或审核，两项分别需要获批的生产适配或独立请求预算。已停止于 G1R，待规划验收。当前无需等待后台任务。
