5. 这次复评更正了哪些此前的说法

  • T2 准确率不是 50.0% / 58.3%。官方对 active_surveillance ↔ continued_surveillance 给 0.5 部分分，正确口径是 A 0.569 / C 0.604（A 有 10 例半分、C 有 3 例）。此前用二值口径低估了两臂。
  • 「净多 4 例」不足以描述差距。按加权 F1，T2 的差距是 0.11；按 macro F1 是 0.23。准确率只差 0.035。
  • T3 的「时间更准」要说清口径。候选的删失感知时间吻合分更高（0.541 对 0.435），但 event=1 病例的月份 MAE 反而更大（16.7 对 13.4 月）。两者不矛盾：前者只罚"预测过早"，后者罚绝对误差。

6. 三个必须声明的方法缺口

  • T2 的工具效率分不可用。本地 72 例 T2 标注的 reveal_sequence 全为空（官方 demo 有 5–6 条），而工具效率用 GT reveal 做分母期望，结果两臂都恒为 1.000，没有信息量。T1 的 GT reveal 齐全（89/91），该项可用。
  • C 臂的段支撑分被投影压低。官方 _reveal_keys 只认带 key 的字典；C 臂提交的 reveal_sequence 已按平台契约投影成段名（radiology_report 等字符串），因此读不到任何 key。两臂段支撑分都在 0.2 左右，对 C 不公平——这是投影层的真实代价，申报时应说明。
  • Judge 是替代品。gemma4:e4b 本地不存在，用了 qwen2.5:7b。要拿到与官方可比的口径，需补该模型或直接走官方 Docker。

7. 对四个研究方向的影响

  1. 决策层：T1 仍无差异，T2 有小幅真实差异（加权 F1 +0.11），T3 基本持平。此前"净多 4 例"低估了 T2。
  2. 推理层：两臂 confidence kappa 都接近 0（T1 0.012 / 0.046，T2 为负）。confidence 占 case score 20%，这是比决策更大的可优化空间，且两臂都没做到。
  3. 段支撑：两臂都只有 0.2。若 reveal 契约能带上 section key，这一项（5% 权重）有确定性提升空间。
  4. Reflection / C 线：本轮 C 臂这两条都是关闭的，所以这次复评无法验证"它们的收益体现在推理质量上"。但评价管线已经就绪，开启后可直接用同一套分数对比——这是下一步最该做的事。
