## 勘误 1：§26「2 个目标属于旧库 2026 条目、v1→v2 无法映射」

**原文**：`covered` 分母是 5，其中 2 个目标属于旧库 2026 条目、v1→v2 无法映射（v2-00467/00468 恒为 None）。

**事实**：`source_index_targets` 里 6 条 query 的 `EAU_2025` 目标共 5 个 id（`unified-0178/0179/0204/0324/0325`），`target_map` 记录它们的 `old_version` **全部是 2025**，且全部映射成功（余弦 0.7926 / 0.8848 / 0.9224 / 0.7392 / 0.7973）。`v2-00467`/`v2-00468` 是 §6.2.1.3 的两条确诊性活检推荐，确实在库内。

名次为 `None` 的原因是**没进重排前 30**，属于检索失败，不是版本无法映射。

**真正无法映射的是另一批**：每条 query 另有 `EAU_2026` 目标（Q01 四个、Q02–Q06 各两个，共 14 个 `chunk-*` id）。v2 是纯 2025，这批没有对应单元，按版本口径排除、不计入分母。

## 勘误 2：§26 覆盖率数字

**原文**：Q01 2/5、Q02 2/5、Q03 3/5、Q04 3/5、Q05 1/5、Q06 2/5。

两处口径错误：

1. **分子重复计数**：`unified-0178` 与 `unified-0179` 映射到同一个 v2 文档（`v2-00271`），命中一条被记成两条。
2. **分母跨 query 复用**：`watch[q]` 是列表且对每个 query 用同一份 5 元目标集合，把不属于该 query 的目标算进分母。

修正后（只算该 query 的 2025 目标、按 v2 单元去重）：

## 勘误 3：§24「表格 unknown = 0」

**原文**：表格页无正文时用 caption 编号回填，最终表格 unknown = 0。

**事实**：那是把 `Table 6.2.8` 的编号 `6.2.8` 直接写进 `section_id`，等于用表号造小节。97 条表格记录里 89 条 `section_id` 与表号相同，其中 38 个编号在正文小节里根本不存在；表 6.2.8（超大分割放疗试验）与表 6.2.10（ADT 联合放疗）因此继承了 `active_surveillance_confirmed`。

另有一层：97 条表格记录只对应 **54 张不同的表**，其余 43 条是同一张表跨页被反复切出（24 组，无一组内容完全相同）。它们会占满有限的召回与重排窗口。

v2r1 的处理：按 caption 合并跨页片段（54 条），章节归属改用正文标题页序列（295 个 `page-section` 对）判定，29 条有依据、25 条显式 UNKNOWN，不再用表号冒充。

## 勘误 4：§18「无关内容归零」

**原文**：无关内容归零（6 条 query 的最终上下文无 `nonclinical` / `epidemiology_background` 条目）。

**事实**：这条只对**非临床噪声**成立。把"临床场景错配"分开统计后，57 条上下文里有 14 条属于临床有效但场景不适用（24.6%），Q06 尤其明显：11 条里 9 条是"活检初筛"语境，而病例是阳性后复评，适用条目 0/11。
