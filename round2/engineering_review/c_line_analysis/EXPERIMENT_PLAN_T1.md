## 二、三组诊断设计

| 组 | 知识库 | P1 回填 | 目的 |
|---|---|---|---|
| A | 原始混合库（2889） | 无 | 旧系统实际基线 |
| B | v2（1080） | **关闭** | 新版知识库 + 检索优化（不含回填） |
| C | v2（1080） | **开启（≤2 节）** | 分支回填的额外贡献 |

另保留 **D 组＝纯 2025 旧切分库（1375）**，只做检索层对照，不跑诊断，用于区分版本变化与切分优化。

30 例 × 3 组 = 90 次完整 Agent 运行。Agent、35B 模型（Qwen3.6-35B-A3B-UD-Q4_K_M）、温度、提示词、后处理全部一致，`clinical_context` 过滤不启用。

## 三、预登记评价指标

### 检索层（每组每例）

| 指标 | 定义 |
|---|---|
| 正确证据覆盖率 | 该例所需指南分支是否进入最终上下文；分母为可映射目标数（排除版本不可映射项） |
| 临床场景适用率 | 上下文中 clinical_context 与病例场景有交集的比例 |
| 证据完整性 | 命中的推荐是否含完整条件与例外（按条目文字核对，非按 id） |
| 非临床噪声数 | doc_type = nonclinical 的条目数 |
| 原始 top5 与 P1 新增分开统计 | 错配发生在排序还是回填 |
| token / 耗时 | 证据输入 token、检索耗时 |

### 诊断层（每组每例）

| 指标 | 定义 |
|---|---|
| 最终决策 | 与病例标签一致 / 不一致 |
| 变化方向 | 逐例记录 正确→错误 / 错误→正确 / 不变 |
| 证据引用正确性 | 引用的推荐是否真实存在、是否被正确转述 |
| 未知条件处理 | 是否把"未记录"当成"阴性" |
| 场景适用性 | 是否使用了不适用于该患者场景的规则 |
| 工具调用次数 / 耗时 / token | 信息成本 |

不只看点估计：逐例配对记录变化方向，报告配对差异与不确定性。

## 四、结果解释规则（预登记）

| 观察 | 后续方向 |
|---|---|
| B 优于 A，C 优于 B | 保留全部优化 |
| B 优于 A，C 低于 B | 新库有效，P1 有负面作用 |
| B 与 A 相近，C 优于 B | 主要收益来自回填 |
| 检索质量改善，诊断无改善 | 转向证据利用与规则执行研究 |
| 场景错配仍严重 | 优先研究临床场景约束检索 |
| 三组均无改善 | 停止扩展，重估研究方向 |
