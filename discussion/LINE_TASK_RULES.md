# CHIMERA 分线任务规则

《研究规划》维护阶段、接收角色、唯一任务入口与验收结论。A、B、C、D 各使用独立执行会话和产物目录。转交、续跑或启动新会话由用户确认。共享工程改动须逐任务登记唯一写入者、范围及时间，生产 profile、模型调用、GPU、数据访问与平台操作按获准范围执行。Codex 统一使用 GPT-6.2 Sol High。

## 共用任务与回报合同

- 任务卡给出研究问题、接收角色、冻结输入与对照、可写范围、资源预算、验收标准、停止条件和私有交付路径。旧任务卡及回执供追溯，重新启动以当前登记为准。
- 一份回报覆盖一条线、一个任务和该交付的所有尝试。首行用 `LINE=<A/B/C/D> | TASK=<编号> | RUN=<标识> | EXEC=<DELIVERED/BLOCKED/NOT_RUN>`。后续依次写结论与范围、验收读数、证据与版本、偏差与失败、实际资源、唯一待裁事项。回报附私有报告和 `handoff.json`，服务器内的关键产物记绝对路径和 SHA-256。
- 计数记单位、分子、分母、版本和未知数。实测为零写 `0`，缺证写 `UNKNOWN`，机器回执用 `null`。准备、实际运行、独立验收和晋级分别登记；`DELIVERED` 表示回报完成，规划另记 `PASS`、`PARTIAL`、`HOLD` 或 `REJECT`。失败、重试、读入、工具、模型、GPU 和时长计入实耗。
- 规则、阶段状态和审查后的汇总进入公开 Git。生成专门的公开副本，逐件审查变更范围。病例原文、标签、参考推理、逐例轨迹、盲包、映射、模型权重和凭据留在授权环境。推送后核对远端提交和文件内容，保留可恢复的 Git 版本。

## A 线 · 自主决策与目标裁定

- 实验前冻结任务目标、决策时点、合法可见视图、模型/采样、工具权限和预算、知识快照、共同诊断与输出消费。Fixed 与 Adaptive 共享初始计划及可比首个观察；Direct ReAct 保留原生循环，另报独立运行全成本。
- 历史归因记录最早可证失配层和候选解释。并列报告预测、理由忠实性、信息单位、工具与模型请求、token、时长和失败分母。单次只改变一个候选。合法停止、预算已满与无合法动作分别核实；留出按风险组隔离，既有基准成绩保留原计分口径。
- 目标或适用性盲审分开制包、临床审阅和锁后对账。具备相关专业资格且未接触标签、预测、选择原因的审阅者只接收去标识的白名单投影与中立说明；示例用合成值。验证角色访问隔离和逐字段原时点依据。字段相关性本身不构成泄漏证据，排除时记录字段权威、可见性与信息损失。缺资格、发现泄漏或时点缺证时登记 `BLOCKED` 或逐案 `UNKNOWN`。锁审阅后才连接标签，选定的历史组只支持其覆盖范围内的解释。

## B 线 · 来源与时间资格

- 保全原值、来源、授权路径、版本、观察身份、日期角色/精度、单位及测量口径。区分值差异、指标或单位误读、不同观察、已认证同次冲突及时间资格未知。同序列配对按无向唯一对计；两次出现、同日或同值不能独立证明观察身份。
- 同槽复核冻结种子、风险组、白名单与输入哈希。运行侧始终 GT 盲，内容读取、存在性、拒绝、异常和失败轮分别登记。用于方法验证的合成覆盖单列。缺合法截止或可比性时，同次冲突、后验可达及纵向资格保持 `UNKNOWN`，计算分母按实际比较单位报告。
- 受保护 M0 为默认基线。M1 只在资格与验收通过后考虑最小来源保留。复杂关系推断或纵向处理另走 M2 研究门，缺时间/观察资格时保持 HOLD。来源注记与运行输入的安全视图分验，避免合法证据被误删。

## C 线 · 检索证据与模型可见性

- 固定查询、语料版本、位置、召回与排序配置。按召回、排序、返回窗、来源映射、证据包及最终请求分别记首次损失，分开比较位置数、互异正文数和满足条件的分级推荐数。目录、摘要或适用性未核材料仅按对应证据角色使用。
- 来源与适用性使用同版原文、原评级、条件和例外。保持条件 UNKNOWN，避免补造分级或阈值。改映射时单独冻结正例与缺证项、保留来源、检查跨载体重复与误拒，离线回读实际序列化请求；模型理解或采纳须另有执行证据。
- 只有可信证据进入候选池后在排序或返回窗丢失才提出固定池重排。只有证据已送达且可复核的模型判断仍误用支持关系或适用性，才考虑轻量判别。每个对照都需记录唯一变项、预算和停止条件。

## D 线 · 外部数据资格

- 先按任务卡上限核对官方发布、许可、版本、字段、决策截止、真实终点、患者和版本去重、潜在重叠及部署约束。输出 `ADMIT`、`HOLD_UNKNOWN` 或 `REJECT`、来源证据与影响范围。公开可得性、独立性和适配性分开证明；项目接触和无法核实的预训练接触分开登记。含共同病例的发布不能相加计独立分母。
- T1 需要本次活检决策标签，病理结果单列；T2 需要治疗推荐目标，已实施治疗单列；T3 需要可认证的时间原点、事件、末次随访和删失规则。候选预筛和真实患者纳入分开统计。`INPUT_SPACE_UNALIGNED` 用于记录合法可得的原始数据无法对齐冻结模型输入或表征的缺口，归 `D-VISIBILITY`。此原因码本身不改变数据访问权限或独立性。
- 合格来源才能进入独立验证。受限外部对照需另定义终点、允许的缺模态或输入映射、分母和解释边界，单独立项与报告。字段或输入空间仍缺证时保留 HOLD，账户申请、患者数据下载、表征重算、模型推理及平台操作须另授权。
