## 目标与依赖

真实 35B A-G2 的 T1/T2/T3 已各跑一例，旧工件冻结。用 [A-G2 规划验收](../../round2/reports/ROUND2_A_G2_ADAPTIVE_HOST_SMOKE_PLANNING_REVIEW_20261119.md)、[执行报告](../../round2/reports/ROUND2_A_G2_ADAPTIVE_HOST_SMOKE_20261118.md)、[官方输入与目标](https://chimera-agent.grand-challenge.org/data-sources-and-imaging/) 和 [B-TIME 验收](../../round2/reports/ROUND2_B_TIME_PLANNING_REVIEW_20261118.md) 查阅依据。F06 的通用 `months` 被共用原始 JSON 后缀送入真实规划、观察后决策、诊断及下游填表。工具实际返回没有记录相应随访，模型将其误表达为观察结果。保留既有运行，修正候选输入边界。

## 执行和验收

1. 在正式 T3 受控候选通路明确按任务、字段语义和可信来源决定可进入决策的 upfront 视图。已证合法的 T3 年龄、术前 PSA、DRE、术前治疗字段和必要身份传输信息保留。通用 `months`、参考 event／复发／末次随访及无来源未知扩展不进入模型决策。若官方允许其他安全的入参，须具体证其版本及语义后列入。独立保全原件、来源及拒绝原因，避免把上游记录修改为临床事实。未经论证不拦截合法工具病理或旧史，不扩大权限。
2. 在既有 Guard 权限检查与模型请求计量之前建立经检验的投影视图。覆盖渲染、完整 JSON 后缀以及任何诊断、后处理或填表的原文旁路。保留已绑定的病例/会话/快照、原始和投影的可追溯关系。生产默认、T1／T2 各自合法字段、工具预算、Adaptive 策略、G1T 精确计量和 T3 输出 schema 不变。正式 B 的迟到隔离继续单列，只复用已有证据和接口，不在本轮部署。
3. 优先复用冻结 F06 作零生成入口检验，保全其原件与上轮双输出，禁止重写原夹具。证明不合格值未进入 planner、观察后策略、诊断或填表，允许字段实际送达、输出两路可回读。用现有负例和最小 T1/T2 路径确认没有误删其他任务合法同名字段。保持错误拒绝、预算计量和输出合同。若发现其他真实候选资格不足，记录准确阻断与最小后继，不新增策略或扩大实验。
4. 接续既有 `upload_readiness.md`，基于实际运行记录核对 D01–D07、现有 builder 与平台 phase 公开的 invoke／进程式协议、设备和限时、模型挂载及依赖清单。只做只读路径／环境核对和准备方案；缺 builder 或 phase 账号证据明确记录。本轮没有安装、构建正式镜像、登录、上传或官网任务。首次正式 validation 若被占用，B 正式范围验收是前置。

只允许改动 T3 受控入口、必要的字段准入接点和针对性无患者回归。真实生成、新病例、GPU、下载和平台操作均为 0。交付后停止。同一病例若需再用 35B，只在本次隔离验收后提交一例的复验提案。冻结既有证据和其他本地修改。正式提交前的独立验收由规划执行。
