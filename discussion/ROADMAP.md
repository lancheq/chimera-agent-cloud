# 路线与门槛

1. 必要精简与可观测性：首轮回放已验收，离线容器条件仍单列。
2. 数据池与质量：版本／历史接触分账，保守分组；冲突不按验证答案选值。
3. 信息权限与成本：执行前检查，患者信息、官方工具分、计算费用分账。
4. 固定／自主候选：共同规划能力，比较观察后是否可修订与停止。
5. 有限对照并分析：阶段指标分开，失败计入全体分母；先证实当前机制，再决定下一步。
6. 后续才研究节点贡献／策略、指南标注／效率／句段／原子化与predictor扩维。
